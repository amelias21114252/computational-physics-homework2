# Computational Physics Homework 2

This repository contains the Python source and figures for Homework 2.

## Files

- `homework2.py`: complete solution for Problems 1–3.

- `smf_cosmos.dat`: galaxy stellar mass function data supplied with the assignment.

- `chi2_vs_step.png`: chi-squared versus gradient-descent step.

- `schechter_fit.png`: best-fit Schechter function compared with the data.

- `homework2_writeup.tex`: LaTeX writeup.
